# Ejercicio 03: Arrays y Tuplas

**Contexto:** Equipos de futbol

## Objetivo

representar listas homogeneas y posiciones fijas con tipos.

## Instrucciones

Crea un array de jugadores y una tupla para el marcador de un partido de futbol sala.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Un array se declara como `string[]` o `Array<string>`.
- Una tupla define el tipo de cada posicion.
- Usa metodos como `push`, `map` o `join`.

## Restricciones

- La tupla del marcador debe tener exactamente dos numeros.
- No mezcles strings dentro del array de goles.
- No uses `any`.

## Reto Extra

Agrega una lista de dorsales y calcula el total de goles.

## Resultado Esperado

La consola muestra plantilla, marcador y total de goles.
