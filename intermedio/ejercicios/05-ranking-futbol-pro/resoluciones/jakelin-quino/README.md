# Solucion: Ranking de jugadores de futbol

## Que hace

Procesa los datos del ejercicio aplicando interfaces, arrays tipados, funciones puras y rankings.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/05-ranking-futbol-pro/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
