# Solucion: Drop de ropa streetwear

## Que hace

Procesa los datos del ejercicio aplicando objetos anidados, filtros, reduce y validaciones.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/18-drop-ropa-streetwear/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
