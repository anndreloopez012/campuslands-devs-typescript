# Solucion: Draft inteligente MOBA

## Que hace

Procesa los datos del ejercicio aplicando union types, Record, Map, Set y reglas de negocio.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/30-draft-moba/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
