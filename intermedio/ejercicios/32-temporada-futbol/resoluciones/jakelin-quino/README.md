# Solucion: Temporada modo carrera

## Que hace

Procesa los datos del ejercicio aplicando clases basicas, generics, scoring y simulaciones.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/32-temporada-futbol/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
