# Solucion: Plan de mantenimiento moto

## Que hace

Procesa los datos del ejercicio aplicando clases basicas, generics, scoring y simulaciones.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/33-mantenimiento-moto/resoluciones/jakelin-quino/index.ts
npm run build
```
