# Solucion: Render farm 3D

## Que hace

Procesa los datos del ejercicio aplicando fechas, estados, reportes y agrupacion de datos.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/48-render-farm/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
