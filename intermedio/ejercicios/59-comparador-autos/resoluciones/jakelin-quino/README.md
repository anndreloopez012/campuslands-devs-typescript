# Solucion: Comparador de autos premium

## Que hace

Procesa los datos del ejercicio aplicando async/await, errores, eventos tipados y datos remotos simulados.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/59-comparador-autos/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
