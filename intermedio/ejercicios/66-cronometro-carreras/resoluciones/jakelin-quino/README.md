# Solucion: Cronometro de vueltas

## Que hace

Procesa los datos del ejercicio aplicando reducers, state machines, unions discriminadas y reglas de interfaz.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/66-cronometro-carreras/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
