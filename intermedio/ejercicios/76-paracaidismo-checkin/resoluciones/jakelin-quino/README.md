# Solucion: Check-in de salto

## Que hace

Procesa los datos del ejercicio aplicando mini sistemas integradores, persistencia simulada y arquitectura simple.

## Como ejecutar

Desde la raiz del repositorio:

```powershell
npm run dev -- intermedio/ejercicios/76-paracaidismo-checkin/resoluciones/jakelin-quino/index.ts
npm run build
```

## Resultados esperados

- Se muestran los datos activos y los totales calculados.
- Se identifica el elemento con mayor valor.
- El caso limite se procesa sin producir errores.
