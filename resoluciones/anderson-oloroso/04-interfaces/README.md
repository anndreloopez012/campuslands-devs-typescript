# Ejercicio 04: Interfaces

**Contexto:** Personajes RPG

## Objetivo

definir contratos para objetos con propiedades obligatorias y opcionales.

## Instrucciones

Crea una interfaz `PersonajeRPG` y usa varios objetos que cumplan ese contrato.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Las interfaces describen la forma de un objeto.
- Puedes marcar una propiedad opcional con `?`.
- Usa arrays tipados con la interfaz.

## Restricciones

- La interfaz debe tener al menos cinco propiedades.
- Incluye una propiedad opcional.
- No uses clases todavia.

## Reto Extra

Filtra los personajes cuyo nivel sea mayor o igual a 10.

## Resultado Esperado

Se muestran personajes RPG validos y los personajes listos para una mision dificil.
