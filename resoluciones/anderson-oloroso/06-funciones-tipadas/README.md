# Ejercicio 06: Funciones tipadas

**Contexto:** Sistema de puntuacion deportiva

## Objetivo

tipar parametros, retornos y funciones auxiliares.

## Instrucciones

Crea funciones para calcular puntos de un equipo segun victorias, empates y bonus ofensivo.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Tipa todos los parametros.
- Declara el tipo de retorno.
- Mantén funciones pequeñas y nombradas por accion.

## Restricciones

- No dejes retornos implicitos en funciones principales.
- No uses variables globales para el calculo.
- No uses `any`.

## Reto Extra

Crea una funcion que reciba varios equipos y retorne el mejor puntaje.

## Resultado Esperado

Se calcula el puntaje total y se identifica el equipo lider.
