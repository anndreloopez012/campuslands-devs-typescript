# Ejercicio 08: Union Types

**Contexto:** Vehiculos deportivos e hiperdeportivos

## Objetivo

permitir valores controlados y discriminar variantes.

## Instrucciones

Crea tipos para vehiculos deportivos e hiperdeportivos y una funcion que describa cada caso.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Usa una propiedad discriminante como `tipo`.
- TypeScript estrecha el tipo dentro de condicionales.
- Los union types ayudan a evitar estados invalidos.

## Restricciones

- La funcion debe aceptar una union.
- Cada variante debe tener propiedades especificas.
- No uses casteos innecesarios.

## Reto Extra

Agrega una variante para vehiculo electrico de alto rendimiento.

## Resultado Esperado

Se imprime una descripcion distinta segun el tipo de vehiculo.
