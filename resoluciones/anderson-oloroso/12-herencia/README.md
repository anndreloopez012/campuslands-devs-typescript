# Ejercicio 12: Herencia

**Contexto:** Personajes de videojuegos MOBA

## Objetivo

reutilizar comportamiento con clases base y especializadas.

## Instrucciones

Crea una clase base `HeroeMOBA` y clases hijas para tanque y asesino.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- La clase hija usa `extends`.
- `super` llama al constructor de la clase base.
- Sobrescribe metodos cuando el comportamiento cambie.

## Restricciones

- Debe haber una clase base y minimo dos hijas.
- No dupliques propiedades comunes.
- Tipa todos los metodos.

## Reto Extra

Agrega una clase soporte con curacion.

## Resultado Esperado

Cada heroe muestra una habilidad especial distinta.
