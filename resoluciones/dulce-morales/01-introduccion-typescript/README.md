# Ejercicio 01: Introduccion a TypeScript

**Contexto:** Videojuegos Shooter
**Alumna:** Dulce Morales

## Que hice

- Declare variables con tipos explicitos (`string`, `number`, `boolean`) para el jugador: nombre, arma principal, municion disponible y estado del escudo.
- Use `const` para los valores que no cambian y `let` para la municion y el escudo, que cambian durante la partida.
- Reto extra: agregue `mapaActual` y `modoDeJuego`.
- Imprimo un resumen legible con `console.log` y template strings.

## Como ejecutarlo

```bash
npm run dev -- resoluciones/dulce-morales/01-introduccion-typescript/index.ts
```

## Salida esperada

```text

Jugador:             Dulce_Sniper
Arma principal:      Rifle de asalto M4
Municion disponible: 90
Escudo:              Inactivo
Mapa actual:         Desierto Rojo
Modo de juego:       Equipo vs Equipo
===============================
```
