# Ejercicio 02: Tipos primitivos

**Contexto:** Motos

## Objetivo

usar `string`, `number`, `boolean`, `null` y `undefined` de forma segura.

## Instrucciones

Modela datos basicos de una moto: marca, cilindrada, estaEncendida, kilometraje y proximoMantenimiento.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- `strictNullChecks` obliga a pensar si un valor puede faltar.
- Usa `null` cuando el valor se conoce como vacio intencional.
- Usa `undefined` cuando todavia no se ha asignado.

## Restricciones

- No uses conversiones innecesarias.
- No uses `any`.
- Incluye al menos cinco tipos primitivos.

## Reto Extra

Calcula si la moto necesita mantenimiento cuando supera 3000 km.

## Resultado Esperado

Se imprime una ficha tecnica de la moto y un aviso de mantenimiento.
