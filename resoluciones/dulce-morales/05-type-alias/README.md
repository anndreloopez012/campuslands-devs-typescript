# Ejercicio 05: Type Alias

**Contexto:** Catalogo de ropa

## Objetivo

crear alias reutilizables para objetos, literales y combinaciones.

## Instrucciones

Define alias para tallas, categorias y productos de ropa de una tienda.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Un alias se crea con `type`.
- Los union literals limitan valores permitidos.
- Combina alias para formar objetos mas expresivos.

## Restricciones

- La talla debe aceptar solo valores definidos.
- La categoria debe estar restringida.
- No repitas estructuras si puedes reutilizar alias.

## Reto Extra

Calcula el precio final con descuento.

## Resultado Esperado

Se imprime un producto con talla valida, categoria valida y precio final.
