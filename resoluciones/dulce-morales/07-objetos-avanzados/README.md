# Ejercicio 07: Objetos avanzados

**Contexto:** Biblioteca de peliculas

## Objetivo

usar objetos anidados, propiedades readonly, opcionales y metodos.

## Instrucciones

Modela una biblioteca de peliculas con director, calificaciones y metodo para calcular promedio.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Usa objetos anidados para director.
- `readonly` protege datos que no deben cambiar.
- Los metodos tambien tienen tipos de retorno.

## Restricciones

- Incluye al menos un objeto anidado.
- Incluye una propiedad `readonly`.
- No modifiques una propiedad readonly.

## Reto Extra

Marca peliculas recomendadas con promedio mayor a 4.5.

## Resultado Esperado

Se muestran peliculas con promedio y recomendacion.
