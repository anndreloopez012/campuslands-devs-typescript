# Ejercicio 09: Enums

**Contexto:** Generos musicales

## Objetivo

agrupar constantes con nombre para opciones conocidas.

## Instrucciones

Crea un enum de generos musicales y clasifica canciones para una playlist.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Los enums evitan strings sueltos repetidos.
- Puedes usar `enum` o union literals; aqui practica `enum`.
- Tipa cada cancion con el enum.

## Restricciones

- Usa un enum real.
- Incluye minimo cinco generos.
- No clasifiques canciones con strings arbitrarios.

## Reto Extra

Filtra canciones por genero.

## Resultado Esperado

Se imprime una playlist filtrada por un genero elegido.
