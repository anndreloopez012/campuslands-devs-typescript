# Ejercicio 11: Clases

**Contexto:** Sistema de motocicletas

## Objetivo

encapsular estado y comportamiento con clases.

## Instrucciones

Crea una clase `Motocicleta` con propiedades, constructor y metodos para encender y recorrer kilometros.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- El constructor inicializa el estado.
- Los metodos modifican el comportamiento interno.
- Usa modificadores como `private` cuando aplique.

## Restricciones

- Debe existir un constructor.
- El kilometraje no debe poder cambiarse directamente desde fuera.
- No uses herencia en este ejercicio.

## Reto Extra

Agrega un getter para consultar el kilometraje.

## Resultado Esperado

Se crea una moto, se enciende, recorre kilometros y muestra su estado.
