# Ejercicio 14: Async/Await

**Contexto:** Consulta de API de peliculas

## Objetivo

trabajar con promesas, funciones asincronas y manejo de errores.

## Instrucciones

Simula la consulta de una API de peliculas usando async/await y datos locales.

Trabaja en `index.ts` y ejecuta el archivo para validar tu avance.

## Pistas

- Una funcion `async` siempre retorna una promesa.
- Usa `try/catch` para manejar errores.
- Simula latencia con `setTimeout` dentro de una promesa.

## Restricciones

- Debe existir al menos una funcion async.
- Debe manejar errores.
- No dependas de una API externa real para completar el ejercicio.

## Reto Extra

Filtra por genero de ciencia ficcion.

## Resultado Esperado

La consola muestra peliculas obtenidas asincronicamente o un mensaje de error controlado.
