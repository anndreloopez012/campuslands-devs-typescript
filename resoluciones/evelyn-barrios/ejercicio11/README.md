# Ejercicio 11 - [Título del Ejercicio] (TypeScript)

Este proyecto corresponde al Ejercicio 11, desarrollado utilizando **TypeScript**. Su objetivo principal es [Descripción breve del objetivo del ejercicio].

## Características

- **Tipado Estático**: Garantiza que las variables y funciones manejen los tipos de datos correctos.
- **Código Robusto**: Reducción de errores lógicos mediante la validación previa a la ejecución.
- **Modularidad**: Organización eficiente de los archivos para facilitar su mantenimiento.

## Diferencias con JavaScript y Justificación

Se ha implementado TypeScript sobre JavaScript basándose en las siguientes ventajas:

- **Detección Temprana de Errores**: Los fallos se identifican durante la compilación y no en tiempo de ejecución.
- **Autodocumentación**: El uso de tipos e interfaces permite comprender la estructura de los datos de forma inmediata.
- **Mantenibilidad**: Facilita la refactorización segura del código en proyectos de mayor escala.

## Estructura del Proyecto

1.  **`index.html`**: Define la estructura de la aplicación.
2.  **`style.css`**: Contiene la definición visual y estilos.
3.  **`src/main.ts`**: Lógica principal desarrollada en TypeScript.
4.  **`dist/main.js`**: Código JavaScript generado tras la compilación.
5.  **`tsconfig.json`**: Configuración técnica del compilador.

## Cómo ejecutarlo

1. Instalar las dependencias necesarias: `npm install`.
2. Compilar el código fuente: `npm run build`.
3. Abrir el archivo `index.html` en un navegador web moderno.
